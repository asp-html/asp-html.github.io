What is Markup Language?

↓ ↓ ↓

Hyper
Text
Markup
Language

"Markup Language" is a way to tell a computer how to understand and display different kinds of text. It forms the skeleton of every website.

HTML is structured with tags. Here is the first document defining the very first HTML tags:

When an opening and a closing tag are combined, they form an element.

↓

All HTML elements require opening and closing tags, like a sandwich where the bun is the tags and the rendered text is the meat, cheese, and veggies.

↓

Opening tags are a letter or word surrounded by < and > characters, like: <bun>

↓

Closing tags are similar to opening tags, but add a backslash before the name, like: </bun>

↓

The final product should look something like this:

↓

<bun> ....meat, cheese, veggies.... </bun>

The modern web is built with HTML's 5th version, HTML5. Now, there are a lot more tags:

<h2> Fundamental HTML Elements </h2>

↓ ↓ ↓

<h3> Body </h3>

The <body> element is the container that all content of a website lives in. Everything you want to be displayed must be wrapped in one <body> element.

<h3> Headings </h3>

Heading elements are: <h1>, <h2>, <h3>, <h4>, <h5>

Headings are meant to be nested sequentially: there should only be one <h1> element on a webpage, main subsections of a site should have <h2> elements, and any subsections of those subsections have <h3>, and rarely, <h4>, and <h5>.

The headings on this page have been written in to show structure.

<h3> Paragraphs </h3>

Paragraphs elements, <p>, contain the body text of a website, like these sentences. Most of the text on a site should be structured with these, in the same way you structure any other piece of writing.

They will separate themselves a bit with default styling.

<h3> Lists </h3>

There are two basic kinds of list elements:

  • Ordered lists, <ol>
  • Unordered lists, <ul>

That was a <ul> element.

Each separate item in a list is denoted with a <li> (list item) element.

What is Hypertext?

Hyper
Text
Markup
Language

Hypertext is what makes the web... a web. Links connect pages together.

Links are structured with anchor tags, <a> and </a>. The opening tag must contain a hypertext reference, like <a href="https://example.com">.

It is always important to make sure your links contain descriptive text, not like:

"Here is a link to the Wikipedia page about anchors,"

but like:

"Here is a link to the Wikipedia page on anchors."

This is that that link looks like:
<a href="https://en.wikipedia.org/wiki/Anchor">Here is a link to the Wikipedia page on anchors</a>

Internet Infrastructure

The US military's Advanced Research Projects Agency Network (ARPANET) was the first wide-area network of computers, and provided the foundation for the modern Internet.

The internet began as a military tool. Then, Tim Berners-Lee adapted those technologies into a new open invention called the World Wide Web, and spread the technology without restrictions.

Tim was also was the primary creator of HTML, adapting it from earlier markup languages.

Now, the internet is international, primarily connected via glass fiber optic cables that run under the oceans and across land
