Yesterday we:

What is a handmade website?

A handmade website is a site you create yourself, about whatever you want.

All code that makes up the site is generated by only you, your brain, and whatever you type with.

Why would we do that?

Handmade website making is the closest way to be understand what the internet is made of. We interact with it every day, so shouldn't we be able to modify it and contribute to it fully on our own?

It provides us with the most creative internet freedom we can find.

Setup

Setting up files:

  • Make a folder on your computer titled "My ASP Website"
  • Create a new file inside that folder, and title it "index.html"

Setting up Visual Studio Code

  • Visit vscode.dev
  • Select "open a folder", and open your "My ASP Website" folder
  • Open your index.html file in the file explorer tab ()
  • Write: !, and hit enter
  • You should have something like this written:

  • Our file is set up! You can edit the file on this site, and save the file from the VSCode window with Ctrl + S or File → Save.
  • If you'd like to make more documents to link between, or add media to include in your documents, just put them all in your "My ASP Website" folder. Instead of copying URLs in image and link elements, just put the filename.

File Previewing

Unfortunately, we can't preview files in vscode.dev.

However, you can copy and paste everything in a VSCode window with Ctrl + A → Ctrl + C, and paste it in a window on write.html.energy to see the live preview. Then, copy that code and paste it back into VSCode when you want to save it.

Alternatively, just open your HTML file in your browser to see it, and refresh that browser page after you save the document in VSCode. The browser view also allows you to interact with links.
