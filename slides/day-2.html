Yesterday we:

What is a handmade website?

A handmade website is a site you create yourself, about whatever you want.

All code that makes up the site is generated by only you, your brain, and whatever you type with.

Why would we do that?

Handmade website making is the closest way to be understand what the internet is made of. We interact with it every day, so shouldn't we be able to modify it and contribute to it fully on our own?

It provides us with the most creative internet freedom we can find.

CSS works alongside HTML to style a website. It has totally different structure and rules from HTML.

Like HTML, CSS is picky, and requires a selector, opening curly bracket, a property with a value separated by a colon, a semicolon at the end of the declaration, and a closing curly bracket.

If your CSS isn't working, ensure it follows those rules.

Location

For our purposes, CSS will go in the <head> element of our documents, surrounded by a <style> element to indicate that it is CSS.

CSS Classes

A CSS class is a way to apply the same styles selectively to whatever element you want.

The selector for a class is ".[class-name]"—it is always started with a period, and must be a single word or words connected with hyphens.

To apply it to an HTML element use the class tag attribute, like this → <p class="class-name"> (the period is removed in the attribute)
