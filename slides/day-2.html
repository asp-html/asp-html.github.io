Setup

Setting up files:

  • Make a folder in Google Drive titled "website", or something else memorable
  • Create a new file inside that folder, title it "index.html"

Setting up Visual Studio Code

  • Visit vscode.dev
  • Select "open a folder"
  • Open your index.html file
  • Write: !, and hit enter
  • Our file is set up! You can save the file from the VSCode window with Cmd + S.
